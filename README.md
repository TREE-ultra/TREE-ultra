## 👋 关于我

我是 TREE，一个喜欢**动手做可视化**的开发者喵。

解析几何里那些漂亮的曲线，我见一个画一个喵。
摄影器材的参数细节……抱歉，传感器尺寸我已经背下来了喵。
至于那些一本正经胡说八道的页面，那纯属手滑喵。

- 🌱 **在折腾**：给圆锥喵补上双曲线的渐近线演示
- 📖 **在读**：继续啃摄影器材规格，想把中画幅镜头也挂到树上
- 🎧 **在听**：写代码的时候放后摇或盯音，循环一整天也不烦
- 💬 **说喵**：欢迎来聊天，或者一起折腾点好玩的

## 🎨 作品

三个纯前端、点开就能玩的网页。没有框架，没有构建步骤。

| 作品 | 是什么 | 在线 | 源码 |
| :-- | :-- | :--: | :--: |
| **圆锥喵** | 拖动 X/Y/Z 三轴平移切面，看平面切圆锥得到圆、椭圆、抛物线、双曲线，以及退化成的点与直线 | [试玩](https://tree-ultra.github.io/-/) | [源码](https://github.com/TREE-ultra/-) |
| **The Camera Tree** | 一棵挂满 21 件真实影像器物的 3D 圣诞树，可检视 CMOS 与画幅 | [试玩](https://tree-ultra.github.io/camera-tree/) | [源码](https://github.com/TREE-ultra/camera-tree) |
| **中国废弃物循环利用股份有限公司** | 一个故意做丑的虚构企业官网，15 页，零圆角、顶死边框、配色令人生理不适 | [体验](https://tree-ultra.github.io/very-ugly-website/) | [源码](https://github.com/TREE-ultra/very-ugly-website) |

> 三个项目的构想、算法推导与代码实现均由 **[DeepSeek](https://www.deepseek.com/)** 协助完成。
> 我负责提点不靠谱的要求，以及反复推翻重来。

## 🛠 技术栈

- **前端** — 原生 HTML / CSS / JS，无构建，无依赖
- **图形** — Canvas 2D（手写透视投影）· Three.js / WebGL
- **方向** — 交互可视化、科普、数学直觉
- **习惯** — 单文件优先，丢到任何地方都能打开

## 💡 一些坚持

- 器材规格以**厂商官方页**为准，逐项交叉核验，连研究来源都写进笔记
- 交互的细节和数据准确性，比堆特效重要
- 教科书的插图如果能拖，就不该只是印在纸上
